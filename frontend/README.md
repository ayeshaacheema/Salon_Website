# Elegance Unveiled

You are an award-winning Product Designer, UX Designer, and Frontend Engineer working for a world-class creative agency.

Your task is to design and build a premium, production-quality website for a real women's beauty salon called **Salon of Beauty** in Islamabad, Pakistan.

I have attached a design inspiration image and I will also provide the salon's Facebook and Instagram pages.

IMPORTANT:

- Use them only for inspiration and content.

- Do NOT copy any existing website or layout.

- Create a completely original experience.

The salon's social media contains real photos of bridal makeup, hair transformations, nail art, skin treatments, salon interiors, customer work, and seasonal offers. Use these as inspiration for the visual direction of the website.

## Vision

I don't want a typical salon website.

I want visitors to feel as if they're browsing the website of a luxury beauty brand or a high-end editorial magazine.

The website should feel:

- Elegant

- Luxurious

- Timeless

- Minimal

- Sophisticated

- Calm

- Warm

- Feminine

- Editorial

- Modern

The design should immediately build trust and encourage visitors to book an appointment.

---

# Design Philosophy

Design an **image-first experience**.

Photography should communicate the quality of the salon.

Keep written content extremely short.

Avoid long paragraphs.

Every section should have:

• a beautiful image

• a short elegant heading

• one sentence (maximum)

• one clear call-to-action

Example:

Bridal Makeup

Your perfect day begins here.

Explore Bridal →

instead of large blocks of text.

The website should tell its story visually.

Use generous whitespace, premium typography, elegant layouts, and subtle animations.

---

# Creative Freedom

Choose your own:

- color palette

- typography

- spacing

- component styling

- visual identity

Create a refined design system suitable for a premium beauty brand.

Avoid:

- bright colors

- childish pink themes

- generic salon templates

- cluttered layouts

- excessive gradients

- overly flashy effects

The final design should feel timeless rather than trendy.

# Featured Offers

One of the salon's strengths is that they frequently launch seasonal promotions and beauty packages.

Design a premium "Featured Offers" section near the top of the homepage.

This should NOT look like a cheap sale banner.

Instead, create elegant promotional cards that feel exclusive.

Examples:

Bridal Package

Reserve your wedding date.

Reserve Now →

Hydrafacial Offer

Limited Time

Book This Offer →

Hair Spa Package

This Month Only

Explore →

Design the section so it can later be connected to a backend where the salon owner can easily update offers.

---

# Mobile Experience

Design mobile-first.

The mobile experience should feel just as premium as desktop.

---

# Code Quality

Write clean, reusable, production-ready frontend code.

Use component-based architecture.

Organize the project professionally.

Structure the frontend so it can easily connect later to a REST API built with Express and PostgreSQL.

Do not implement backend functionality.

---

# Final Goal

Imagine this website is being presented to the actual owner of Salon of Beauty.

It should be beautiful enough that they would immediately want to replace their current online presence with it.

The website should feel like a premium digital experience rather than a salon template.

Surprise me with thoughtful layouts, exceptional UX, elegant typography, refined visual storytelling, beautiful photography, interactive elements, and a memorable user experience.

Create something worthy of being featured on Awwwards while remaining practical, intuitive, and easy for customers to use.
